# K0LUMNA
A Simulated SOC analysis platform &amp; incident response training simulator

### **K0LUMNA** (K-0)
A hands-on cybersecurity training simulator built to replicate real-world Security Operations Center (SOC) workflows. It bridges the gap between theoretical security concepts and practical threat analysis by providing a simulated SIEM dashboard, automated log parsing, and interactive triage workflows. 

Designed to be a backbone of SOC training.
